# Lyric Lens

Lyric Lens は、TextAlive App API で再生される楽曲に合わせて、歌詞の瞬間をカメラのシャッターのように切り取るWebリリックアプリです。

楽曲を流しながら、歌詞・ビート・コード・サビ・声の強さに反応する撮影画面で「リリック写真」を撮影し、最後に撮影ログを短い音楽ログとして振り返れます。

## 体験ページ

基本的には、デプロイ済みのWeb版をブラウザで開いて試してください。

```text
公開URL: https://lyric-lens-985.pages.dev/
```

カメラを使う場合は、スマートフォンまたはカメラ付きPCで開くのがおすすめです。カメラを許可しなくても、アプリ内のビジュアル背景だけで体験できます。

## まず試してほしい流れ

1. 公開URLを開きます。
2. 楽曲は最初から選ばれている `シャッターチャンス / 夜未アガリ` のままで始めるのがおすすめです。
3. PCで実カメラを使う場合は、必要に応じて `カメラ確認` を押して使うカメラを選びます。
4. `撮影 START` を押します。
5. 音楽が読み込まれたら、再生ボタンを押して曲を流します。
6. 画面下の丸いシャッターボタンで、好きなタイミングを撮影します。
7. `AUTO` がオンのときは、歌詞のキーワードに合わせて自動でシャッターが切られることがあります。
8. 何枚か撮影したら `現像` を押します。
9. 現像画面で `PLAY MUSIC LOG` を押すと、撮影ログを曲付きで見返せます。
10. 必要なら `再生成` で自動編集を作り直し、`保存` で映像または画像を書き出します。

## 画面ごとの使い方

### 1. 楽曲選択

最初の画面では、体験する楽曲を選びます。

プリセット曲:

- シャッターチャンス / 夜未アガリ
- こたえて / imie
- アフター・ザ・カーテン / Rulmry
- 世界最後の音楽隊 / 夏山よつぎ×ど～ぱみん
- トリツクロジー / 鶴三
- TAKEOVER / Twinfield

`カスタム URL` を選ぶと、TextAlive対応の piapro URL を入力して試せます。

### 2. 撮影画面

撮影画面では、楽曲に同期したカメラ風のビューファインダーが表示されます。

- 再生ボタン: 楽曲を再生/一時停止します。
- AUTO: 歌詞キーワードに合わせた自動シャッターをオン/オフします。
- FILM: 撮影時の色味や質感を切り替えます。
- 丸いシャッター: 手動でその瞬間を撮影します。
- 現像: 撮影したログの確認画面へ進みます。

カメラを許可している場合は実際のカメラ映像に歌詞が重なります。カメラを使わない場合も、楽曲に反応するビジュアル背景で撮影できます。

### 3. 現像画面

現像画面では、撮影した画像と撮影ログを確認できます。

最初に表示される `STORY` では、撮影した画像から短い縦型の自動編集ログを作ります。

- `PLAY MUSIC LOG`: ブラウザ内で曲を流しながら、撮影ログを見返します。
- `BLACK / LOG`: 自動編集の見た目を切り替えます。
- `AUTO / 1 BAR / 2 BEAT`: 写真が切り替わるテンポを切り替えます。
- `再生成`: 見た目やテンポの変更を反映して作り直します。
- `保存`: 自動編集動画を保存します。

`FRAMES` に切り替えると、撮影した各画像を一覧できます。画像ごとに `FILM ON/OFF` を切り替えたり、個別に保存したりできます。

## 保存について

- 自動編集動画の保存は映像のみです。
- 保存した動画ファイルには楽曲音声は入りません。
- 曲付きで振り返る体験は、ブラウザ内の `PLAY MUSIC LOG` で楽しんでください。
- 撮影画像はブラウザ内で処理されます。サーバーへアップロードする用途のアプリではありません。

## うまく動かないとき

### 音楽が再生されない

- ブラウザの自動再生制限により、最初はユーザー操作が必要です。再生ボタンを押してください。
- 通信状況によって、TextAliveや楽曲データの読み込みに時間がかかることがあります。
- ページを再読み込みしてから、もう一度 `撮影 START` を押してください。

### カメラが使えない

- ブラウザのカメラ許可を確認してください。
- iPhone/Androidでは、HTTPSの公開URLで開いてください。
- カメラを許可しなくても、ビジュアル背景だけで体験できます。

### 保存できない

- ブラウザや端末によって保存の挙動が異なります。
- スマートフォンでうまく保存できない場合は、PCブラウザでも試してください。
- 自動編集の生成中は保存できません。生成が終わってから `保存` を押してください。

## 開発者向け

ローカルで起動する場合は、TextAlive App Token を `.env` に設定します。

```bash
npm install
cp .env.example .env
```

`.env`:

```bash
VITE_TEXTALIVE_TOKEN=your_token
```

開発サーバー:

```bash
npm run dev
```

ビルド:

```bash
npm run build
```

スマホ実機でローカル開発版のカメラを使う場合、通常の `http://192.168.x.x:5173` ではブラウザがカメラを許可しないことがあります。HTTPSで配信するか、HTTPSトンネル経由で開いてください。
